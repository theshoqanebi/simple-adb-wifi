## 📦 Installation

1. Download the latest APK from the [Releases](https://github.com/theshoqanebi/simple-adb-wifi/releases) page.  
2. Install it on your Android device (make sure **root** is enabled).  
3. Launch the app → Tap **Enable ADB over Wi-Fi**.  
4. Connect from your PC via:  
   ```bash
   adb connect <device-ip>:5555
